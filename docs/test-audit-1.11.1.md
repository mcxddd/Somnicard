# 1.11.1 全游戏回归记录

测试日期：2026-10-23。以 1.11.0 为基线，覆盖规则、界面、复盘、训练、教学与 AI 配置，并修复测试发现的紧凑牌桌遮挡。

## 本次修复

训练室牌桌比普通对局矮。原来部分下注标记向桌内摆放，可能压住翻牌、其他座位或另一位玩家的下注标记；九人训练局可以稳定复现。

现在先保留各座位的原位置，再对发生遮挡的标记寻找附近空位，同时避让公共牌、底池、玩家面板与其他下注。八人紧凑桌下移上侧两位玩家，为顶部三人的下注留出空间。普通牌桌没有遮挡的位置保持原位。

新增回归覆盖两种手机尺寸下的 2～9 人紧凑桌，包括所有座位同时显示下注的拥挤状态。这个拥挤状态只在测试中构造，不改变真实牌局规则。

## 测试边界

- 本轮没有连接安卓真机，环境也没有可运行的 Android 模拟器。桌面合成手势与截图不能代替实际触摸、软键盘、后台切换、系统文件选择器和手机性能验收。
- Android Keystore 插件做构建和 APK 静态核验；真正的安卓加密读写仍需设备测试。Windows DPAPI 已实际执行。
- 没有用户服务密钥，在线流程采用本机模拟 HTTP；未测试真实提供商的回复质量、延迟、费用或模型牌力。
- 本次不改扑克规则、电脑策略、AI 协议或 GTO 求解器。1.11.0 的 21,312 手本地评测与六个河牌抽象的独立 LP 对照作为已有证据保留，没有把它们计作本轮新增实测。完整多人 GTO 仍不在已支持范围内。
- 自动测试通过只代表本次覆盖内未再发现问题，不代表不存在其他缺陷。
