# Somnicard 1.12.0

本地对手拥有名字，桌边发言围绕当前牌局，并补上 Android 模拟器验收。

## 对手身份

本地电脑默认显示小夏、阿岚、米洛、青禾、诺亚、橙子、阿澈、星野。设置 → 电脑对手，选座位即可修改名字；无需开启在线 AI。名字在牌桌、座位详情、教学说明、存档与复盘中一致。减少人数仍保留离桌座位的配置，取消设置不应用改名。

记录层保存座位名字，使连续牌局、训练分支与 JSON 复盘保留身份；旧记录中的原有名字仍按记录回放。

## 桌边发言

在线对手以自己的口气回应刚发生的动作、下注或公共牌，可以打趣、吐槽、试探和虚张声势。发言只收到公开信息、本人最近一次公开动作，以及本手最近的桌边对白，不会收到任何人的底牌。性格与激进程度仍影响语气；没有具体内容可以保持沉默。

不要求寒暄、自我介绍或教学式分析。增加空话、问好、角色说明、格式痕迹和重复内容过滤；最多 36 字，保留短句。上一轮尚未返回的发言不会在下一轮显示，复盘把发言锚定到请求时的动作位置。每位对手每手的发言请求仍有上限，不增加自动刷屏。

这改善了提示、显示与时序约束；没有真实模型密钥，本次没有实测外部模型的语言质量或牌力。模拟回复用于接口测试，不作为真人感的模型评测。

## 安卓返回键修复

模拟器实际按键发现引擎默认的 `quit_on_go_back` 仍开启，安卓返回键会直接终止应用，绕过已有的分层返回。现在由游戏管理返回动作：关闭上层面板、返回上一层，主界面才显示退出确认。

根因依据：[Godot SceneTree.quit_on_go_back](https://docs.godotengine.org/en/stable/classes/class_scenetree.html#class-scenetree-property-quit-on-go-back)。桌面 Esc 与安卓返回使用相同的导航层级。

设置页现在按软键盘的实际高度缩短面板，把当前输入框滚动到可见区域，底部保存 / 取消按钮保持在键盘上方。键盘收起后恢复原高度，适用于名字、地址、密钥和其他设置中的输入框。
