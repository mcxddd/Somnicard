# 界面规范

所有界面组件都在 `scripts/ui/style.gd` 里，新页面直接用这些函数，不再单独写字号和颜色。

## 文字层级

| 函数 | 字号 | 颜色 | 用途 |
| --- | --- | --- | --- |
| `UI.title()` | 28 | 正文色 | 页面或主卡片的大标题，一屏最多一个 |
| `UI.heading()` | 21 | 金色 | 分区标题 |
| `UI.body()` | 19 | 正文色 | 正文 |
| `UI.caption()` | 15 | 灰色 | 说明、注释、次要信息 |

以上都会自动换行。

## 颜色用途

- 正文色 `TEXT`：内容本身。
- 灰色 `MUTED`：辅助说明。
- 金色 `GOLD`：只用于分区标题和一张卡片里最重要的那个数字，不用来强调普通文字。
- 绿色 `GREEN`：只用于一屏里最主要的那个操作按钮。
- 评级：好的选择 `SUCCESS`（绿）、可以接受（金）、偏离建议 `DANGER`（红）。

## 卡片

`UI.card(kind)`：

- `"hero"`：一屏里最主要的那张卡片（主界面开局卡、训练室“今天 · 5 题”）。
- `"card"`：普通分组。
- `"inset"`：嵌在其他卡片里的内容块，没有阴影。

## 按钮与入口

- 层级：
  - `UI.primary()`：主要操作，绿色实心，一屏只放一个。
  - `UI.secondary()` / `UI.button(文字, 回调, 颜色)`：实心次要操作。浅色填充（如加注金色）自动配深色字。
  - `UI.outline()`：透明底细边框，用于返回、收起、取消。
  - `UI.link()`：只有文字（绿色），用于“完整分析 ›”这类行内入口。
  - `UI.icon_button(图形, 名称, 回调)`：代码绘制的方形图标按钮，图形有 `pause`、`play`、`more`、`close`、`back`；`text` 保留名称供提示和测试。
- 尺寸：任何高度都会归到 44 / 50 / 58 三档（64 以上的牌桌操作按钮除外），圆角统一 12。
- 质感：实心按钮底边 3 像素深色，按下时变 1 像素并让文字下移 2 像素；禁用时与背景混合变淡。
- 焦点框：所有按钮共用一个金色焦点框，只在键盘或手柄输入后显示，点按或鼠标点击后隐藏（`UI.show_focus()`）。
- 牌桌操作配色：弃牌用线框，跟注 `ACTION_CALL`（亮绿），加注 `ACTION_RAISE`（浅金配深色字），全押 `ACTION_ALL_IN`（红）。
- `UI.entry(标题, 说明, 回调, 图标名, 竖排)`：导航入口。左侧图标，右侧大标题加一行灰色说明，横排时最右边有箭头。按钮的 `text` 保留“标题 + 换行 + 说明”的纯文字，供无障碍和测试读取；需要更新内容时用 `set_lines()`。入口里的文字不自动换行，要分行就在说明里写换行符，过长时以省略号结尾；入口高度会随行数和进度条自动增加。

## 选择与开关

- 两到三个短选项用 `scripts/ui/segmented.gd`（并排的分段按钮），不用下拉框。它提供和下拉框相同的 `add_item`、`select`、`selected`、`item_selected`。
- 开关用 `CheckButton` 配 `UI.switch_icon(开/关)`，放在文字右侧，竖屏时也不换行。
- 设置仍然是“改好后点保存”：对手难度等改动会影响正在进行的牌桌，一次性保存才能让牌局记录里的对手变化只记一次。

## 显示大小

“外观与声音 → 显示大小”通过窗口的内容缩放实现：小 590×1049、标准 540×960、大 510×907 的逻辑画布。界面整体放大或缩小，布局代码不需要区分字号。牌桌最多 6 人，大号下公共牌也不会被座位挡住。

## 动效

`UI.motion` 控制界面动效，跟随“牌局动效”设置，省电模式、无头测试和截图时关闭。

- `UI.button()` 和入口行按下时缩小到 96%（`UI.press_feedback()`）。
- 设置、复盘、训练室、学习路线、帮助和新建牌桌打开时淡入（`UI.fade_in()`）。
- 底池增加、摊牌赢下底池时，底池数字和赢家座位轻跳一下（`UI.pop()`）。
- 牌桌筹码：新下注从座位滑到下注标记，换街收进底池，结束时飞向赢家（`table_motion.gd`）。复盘只在逐步前进和自动播放时播放，拖动、跳转和后退时直接切换。

## 数据展示

- `UI.stat(数值, 标签, 颜色)`：一个大数字加一行小标签。
- `UI.stat_row([[数值, 标签, 颜色?], ...])`：等宽的一排数字，放在嵌套卡片里。用于训练室概览、本组总结、复盘历史统计、学习路线进度和结论卡的关键数字。
- `UI.progress(比例)`：细进度条，绿色填充。入口行可用 `set_progress(比例)` 在说明下方显示，比例为负时隐藏。
- 结论标签：彩色文字配同色 14% 底和 45% 细边框，放在卡片右侧（训练本组总结的每题结论）。
- 教练读牌：每位对手一行，“强牌 / 中等 / 听牌 / 空气”的比例加最常见的三类起手牌；翻牌前改为“范围集中在约 X% 的起手牌”。
- 颜色：盈利、好的选择用 `SUCCESS`，亏损、偏离和待复习用 `DANGER`，每排最重要的一个数用金色。

## 说明文字

- 帮助只放在“帮助与关于”一处，按七个主题分组，每个主题下是可展开的问答卡片。牌桌菜单里的“玩法帮助”直接打开“牌桌与操作”。
- 建议准确性的说明只写在“帮助 → 教练与复盘”，其他页面用一句话指向那里，不再重复整段免责说明。
- 写法：先说结论，再给一个例子；一个回答只回答一个问题。

## 首次打开引导

`scripts/ui/onboarding.gd`：新安装时在主界面上方显示三页简介，可以跳过，返回键也会跳过。看完或跳过后写入 `user://onboarded`，之后不再出现；这个标记文件不在偏好设置和备份里。已有牌局记录或偏好设置的老用户启动时直接视为已看过。自动测试和截图默认不显示，截图可用 `--onboarding --onboarding-page=N` 查看指定页。

## 图标

图标放在 `assets/icons/<名称>.png`，128×128 透明背景（512 像素原图在 `assets/icons/source/`）。`UI.icon(名称, 尺寸)` 找不到文件时返回空，入口里就不显示图标，所以图标可以分批补上。当前用到的名称：

| 名称 | 位置 |
| --- | --- |
| `learn`、`train`、`review` | 主界面的学习路线、训练室、牌局复盘 |
| `topic-preflop`、`topic-facing`、`topic-betting`、`topic-river` | 训练室四个主题 |
| `history` | 训练室练习记录 |
| `settings-table`、`settings-look`、`settings-coach`、`settings-opponents`、`settings-data` | 设置的五个分类 |
| `review-mistakes`、`lesson`、`lesson-done` | 学习路线的错题复习、未完成课程、已完成课程 |
| `help` | 帮助与关于的问题列表（主题图标缺失时的替代） |
| `help-start`、`help-table`、`help-coach`、`help-opponents`、`help-privacy`、`help-install`、`help-about` | 帮助的七个主题 |
| `home` | 牌桌菜单的“返回主界面”（待生成） |
