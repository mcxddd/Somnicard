# Somnicard 1.2.0：手机竖屏

Android 默认竖屏，versionCode 6，包名仍为 `com.somnicard.practice`。桌面默认横屏，可通过 `tools/run.ps1 -Portrait` 打开 450×850 的手机比例窗口。真机验收按用户安排暂缓，本次没有连接、安装或操作手机。

## 布局与操作

- 按窗口方向切换两套布局，竖屏基准 540×960、横屏基准 1440×900，按比例扩展。切换时沿用同一牌局实例，保留筹码、行动者、下注草稿、设置草稿和复盘步骤。
- 双人桌突出双方手牌；3–9 人桌以紧凑座位显示名字、筹码与行动，自己固定在下方。点击座位查看公开信息；多人摊牌后的手牌通过座位详情或复盘结算查看。
- 竖屏底部保留弃牌、跟注/过牌、加注三个主要操作。加注打开底部面板，含金额、±1 BB、BB 档位、底池比例、滑条与全押；选档不下注，提交才行动。全押保护沿用上一版。
- 顶部保留单位、暂停和“更多”；设置、换桌、历史、行动记录与横竖屏切换收进菜单。横屏顶部“竖屏”可切回来；手机每次启动默认竖屏。
- 入座页与设置页可滚动，设置的取消/应用按钮固定可见。打开页面暂停电脑，返回保持原来的暂停状态。Android 安全区域与加注面板软键盘避让已接入，实际设备表现仍待验证。
- 竖屏历史改成可直接点击的牌局卡，分别显示时间、桌型/手数与净变化，避免金额被长行挤掉。
- 复盘拆成“牌桌回放 / 决策分析”两个页签；回放保留时间轴、前后步、播放、我的决策、下注轮次。分析整页滚动，切换页签不改变步骤。横屏仍并排展示。

BB / 筹码在牌桌、加注面板与复盘同步。真实金额仍为整数筹码，切换显示不影响已经输入的数量。历史记录、当前桌存档和偏好格式不变。

## 验证

桌面窗口检查了 360×640、390×844、412×915 等手机比例及 1280×800 横屏。实际渲染覆盖双人、6 人、9 人、结算、加注面板、全押确认、设置、历史、复盘与分析。

新增 `tests/portrait_test.gd`：覆盖 2–9 人座位及公共牌边界、按钮可达、三种手机比例、真实电脑完整牌局、金额切换、加注提交/取消、全押保护、菜单目标、设置草稿与横竖屏切换、复盘游标保持。1414 项检查通过。原规则、UI、多人对战、复盘/恢复、设置交互与完整启动回归也通过。

这些结果属于电脑窗口与自动化检查；不等同于安卓真机字体、触摸、软键盘、刘海/手势区、生命周期或性能验收。

完整回归计数：规则 8149、原 UI 26、多人 UI 1249、复盘/恢复 12613、设置交互 112、竖屏 1414，全部 0 失败；完整启动检查通过。多人 UI 计数随随机牌局长度变化。
