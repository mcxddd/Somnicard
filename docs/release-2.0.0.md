## 本次完成的产品更新

- 首页重组为开桌 / 继续、学习路线、训练室、牌局复盘、设置、帮助与关于；展示真实课程进度和当天训练次数。
- 学习路线含 8 个主题、24 个有固定答案和具体理由的决策题。答错可重试，已掌握知识点不会因复习答错消失，所有课程可自由进入。
- 学习进度与牌局、收藏、备注、训练记录一起备份；重复导入不重复累计知识点或尝试次数。
- 牌桌增加多层桌沿、细微绒面纹理和品牌水印，保留紧凑座位和中央公共牌区域。
- 启动使用项目自己的品牌图标，不增加最短等待时间；牌桌与首页共享帮助中心。
- 5 个原创短音效分别反馈发牌、行动、轮到自己、净赢和分池。静音、轻声、标准音量独立选择；可选短震动；切到后台立即停音。
- 新增“声音与性能”设置，标准 60 FPS / 省电 30 FPS；不改变对手的策略强度。
- 分层帮助覆盖操作、教练、AI 连接、隐私、备份、安装排错；诊断摘要只含版本、系统、引擎和显示信息，由用户主动复制。
- 展示 Godot 与第三方组件的许可证和归属信息。
- Android GL 渲染在 Activity 暂停时先停止，避免 HOME 切换时渲染线程与 surface 销毁竞争。禁止扑克桌进入画中画，离开应用时暂停。
- 官网页面介绍实际玩法、课程、AI、GTO 范围、安装迁移、隐私与反馈方式；使用真实游戏截图。正式部署为纯静态 HTML/CSS，不依赖 JavaScript 才能下载。

## 延续的完整玩法

支持 2–9 人无前注、无抽水的虚拟筹码练习桌，50/100/200 BB 初始筹码，逐座位本地难度 / 风格 / 名字或在线模型档案。完整四街下注、合法加注、全押、边池、零头分池、摊牌、连续下一手与当前桌恢复。

教练可在桌内开关与配置；历史有稳定牌局 ID、筛选、收藏、备注、关键决策、逐步回放与原局分支练习。AI 对手按可见信息决策，独立桌边发言，普通记忆限同桌，保存的陪练可跨桌延续。连接失败提供有界重试与本手本地接管。

## 策略与 AI 边界

本地数值分析和策略算法在本版没有被重新包装为“完整 GTO”。高级 CFR 仍限定双人河牌抽象范围与有限下注树；多人、前几街等使用范围权益与经验建议。短期成绩和难度标签不能映射成真人段位。在线模型需要用户自己的兼容服务，费用、可用性与内容质量取决于该服务。

本版是完整的个人扑克练习产品方向，未包含真人网络桌、账号云同步、锦标赛、排名、商店支付或现金游戏。这些不是现有入口背后的未实现功能。

## 正式发布门槛

1. 确定安装身份：独立正式签名 / 新包名，或沿用测试版身份覆盖更新。用户暂不正式发布，此选择推迟。
2. 生成非调试构建，核对版本、包名、签名、权限、ZIP CRC、16 KB ZIP / ELF 对齐，确认不含测试脚本、站点或凭据。
3. 对确切正式包进行两系统启动、游玩、后台恢复与迁移验证；不能以隔离测试 APK 代替正式包验证。
4. 先上传版本化 APK 并验证完整下载与 Range，再更新官网下载页；保留旧包和网关回滚配置。
5. 实际公网核验通过后，将本文件状态改为已发布，并填入文件大小、SHA-256、证书摘要和下载链接。
