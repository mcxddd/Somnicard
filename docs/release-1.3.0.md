# Somnicard 1.3.0

离线范围与教学版本；Android versionCode 8，保留包名与原有历史/设置/当前桌存储路径。

## 新功能

- 2–9 人对手范围按公开位置、有效初始深度、行动、下注尺度与当时牌面更新；合法组合加权抽样，联合排除撞牌。
- 可展开的 169 类范围图、对手选择、有效组合数与类别概率。
- 限定双人河牌的 CFR 抽象求解：混合频率、模型内可利用度、收敛目标和明确的支持范围。8 档牌力，每方 64 个范围样本，单次半池/满池下注，无再加注。
- 电脑升级为有样本预算的范围加权模拟与混合动作，不宣称 GTO 对手。
- 对局和复盘教学独立开关并持久化，关闭立即取消分析、隐藏建议，普通游戏与回放继续可用。
- 竖屏教学上下文手牌、主要建议与理由、按需范围图、复盘实际操作对照、分析页直接跳下个决策。
- 下注快捷档位触摸高度增加，原有 BB/金额精确切换、全押确认与单独提交保留。

## 边界与大模型

范围似然仍为经验模型，未经人群数据校准；CFR 是有限抽象内的均衡参考，不是完整德州 GTO。未来下注、档内阻断差异、完整再加注树和多人均衡没有被覆盖。旧历史兼容，重新分析时使用新模型。

当前教学不需要大模型，本轮没有接入 API 或开启网络权限。未来可选用于自由问答与个性化讲解，不负责算牌、求解或下注。完整依据见 [策略与教学设计](strategy.md)。
