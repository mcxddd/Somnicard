# Somnicard 1.4.0

根据用户首次手机实测反馈改进。Android versionCode 9，包名、签名与存储路径沿用，支持直接覆盖 1.3.0，勿卸载旧版清除记录。

- 结算明确显示平分底池；分别赢得主池、边池不会误标平局。座位与中央显示扣除投入后的净输赢，增加淡入动效；关闭“牌局动效”时立即显示。
- 多人摊牌直接显示未弃牌对手的手牌，点座位可查看筹码和牌型；弃牌者的隐藏手牌仍不公开。
- 六人桌改为一位在顶端、两侧各两位；九人桌与较短屏幕的座位间距通过检查。
- 教练采用原生绘制的圆形头像，可关闭、放左或右、手动或自动提示、选择简洁或详细理由。在牌桌内显示自己的手牌和建议，仍可下注；收起或返回可停止分析。详细范围和 CFR 信息按需进入。
- “练习设置”统一改为“设置”；“电脑思考速度”改为“对局节奏”，明确它只调整行动间隔。独立新增入门、标准、进阶电脑难度，调整模拟预算、范围使用与决策噪声，不使用隐藏信息。
- 加注缩短为常用档位、金额输入和滑条；翻前显示最小 / 2 / 2.5 / 3 BB，翻后显示最小 / 1/3 / 1/2 / 满池。隐藏冗余 ±1 BB 和重复单位选择，保留主界面单位切换和全押保护。
- 历史卡片支持触摸和鼠标拖动、惯性滚动、滚动后点击；拖动时取消打开，返回列表保留页码和滚动位置。
- 牌桌、历史卡片、复盘显示稳定 ID，新记录保存 ID；旧记录由相同初始信息生成 ID，不改写旧文件。ID 为初始状态的截短 SHA256，不是可解码的牌堆。
- 决策分析先显示建议与理由，再用指标和条形图比较预计分池份额与跟注门槛，保留静态模型和近似范围的说明。

本版没有扩展 GTO 求解范围、接入大模型或加入网络权限。难度档位尚未通过长期胜率基准校准。

验证：规则、UI、多人对战、历史复盘、范围/CFR、设置体验、竖屏回归均通过。新增反馈测试覆盖平分与边池区别、摊牌隐藏边界、ID 的 JSON 稳定性、教练作业生命周期、所有难度的 2/6/9 人完整牌局及隐藏信息隔离、真实输入分发下的历史拖动与点击。检查实际渲染的六人教练、九人摊牌、加注、复盘分析与教练设置。手机触感、低端机性能仍需用户安装新版后验证。

发布验证：8 组测试共 31,415 项检查通过，另启动烟测完成四轮下注与摊牌。v2/v3 签名、与旧版签名一致、16 KB 对齐、ZIP 完整性通过；确认新教练与滚动脚本已进入 APK，未带入测试、工具或用户附件。安装包为 57,209,689 字节，SHA256 `6f3b2b13be5933d167314a949b31e2651a77aa5b00b4183e7e473c24234fc58e`。服务器公网完整下载与末尾续传内容均核对一致。
