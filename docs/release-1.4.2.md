# Somnicard 1.4.2

Android versionCode 11。针对竖屏牌桌拥挤重新安排信息层级，继续支持 2–9 人桌；包名、签名和本地存档路径沿用。

- 顶部合并为一行桌型、手数与控制。牌局 ID 移至“更多 → 本手行动记录”，历史和复盘仍可查看完整 ID。
- 普通座位去掉厚边框与阴影；仅行动者、获胜者突出显示。取消重复的“等待行动”，自己的行动提示和净输赢集中在底部。剩余筹码字更大，座位仍保留两张牌背与实际摊牌。
- 多人桌增加左右座位的纵向间隔，常规竖屏将下注筹码放在对应座位下方，短高度保留内侧避让。下注金额增大字体和容器宽度，中间继续显示累计底池。
- 桌布移除密集纹理、多重装饰框和水印；尚未发出的公共牌只显示轻轮廓，减少深色方块。
- 对局教练使用更短的浮层，优先手牌、推荐与概率。设置、详解、收起位于同一行；长解释在浮层内部滚动，公共牌和底部行动按钮不被覆盖。
- 复盘默认“简览”：建议、预计分池份额、跟注门槛、原因。点“详解”显示策略频率、范围与计算说明，再点“简览”收起，回放步骤保持不变。教学近似范围没有改变，详解保留原来的模型局限说明。
- 回放的步骤与当前行动合成一行，公共牌、时间轴和回放按钮继续同屏显示。

验证：9 组自动检查通过，包含 270 手规则模拟、2–9 人桌几何检查、下注金额不截断、长篇教练滚动、防遮挡、简览/详解保持同一决策及 UI 冒烟。360×640 实际桌面渲染检查覆盖九人桌、摊牌、对局教练、复盘简览；另检查双人和六人桌。未进行新版 Android 真机验收。
