# Somnicard 1.8.0 · 在线 AI 对手与长期陪练

Android versionCode 19。包名与调试签名沿用，覆盖安装保留原有牌局、设置和训练记录。本版首次启用 INTERNET 权限；默认仍使用本地电脑，只有主动测试连接或启用在线座位才发送请求。

## 开始使用

1. 主界面 → 设置 → AI 服务与陪练，填写服务前缀地址（例如 `https://你的服务/v1`）、模型 ID 与 API Key。也接受完整 `/chat/completions` 地址。
2. 点击“测试连接”，这会发送一次不含牌局资料的请求。成功后保存设置。
3. 设置 → 电脑对手，逐个座位把来源改为“在线 AI”，配置名字、性格、决策目标和行动风格，然后保存。2–9 人桌可混用本地与在线对手。
4. 可以直接开新桌；在正在进行的牌桌保存后，从下一次决策生效。模型等待时间取决于服务，“对局节奏”只影响行动间隔。
5. 重启应用后需重新输入密钥。密钥仅本次运行保留，不写入偏好、存档、历史、训练备份或 APK。无需密钥的代理允许留空。

服务必须兼容非流式 Chat Completions。默认发送 `max_tokens: 1024`；服务要求新参数时切换 `max_completion_tokens`。JSON 模式可选，服务需支持 `response_format`。默认 45 秒超时，可选 10–120 秒。远程服务使用 HTTPS，本机调试允许回环 HTTP；不跟随重定向。

## 对手与记忆

每个座位有独立名字、性格、难度目标、激进程度和记忆。同一开桌的连续多手保留记忆；恢复同桌延续记忆，重开桌清空临时身份记忆。名字和打法配置仍会保留。

临时对手可保存为长期陪练。陪练下次入座读取自己原有记忆，最多保存 32 位，同一陪练不能同时占两个座位。长期陪练库可重命名、清空记忆或删除；清空与删除需确认，档案操作立即生效。删除后当前座位成为临时身份。当前本地训练备份不包含 AI 档案；卸载或清除应用数据会丢失它们。

记忆是可核对的事实：观察到的手数、人类玩家主动入池 / 有加注 / 弃牌的手数，以及最近 8 手行动摘要。每手完成只更新一次，保存有限去重标识；不把模型自由编造的总结或私有推理写入长期记忆。当前手最近最多 100 条公开行动同时提供给模型。记忆是有界摘要，不是无限上下文或模型微调。

| 档位目标 | 给模型的打法约束 |
|---|---|
| 入门 | 范围偏宽、跟注偏多，位置和赔率判断粗略；不要求故意送筹码 |
| 标准 | 考虑位置、赔率、深度、人数及公开行动；选择性价值下注和诈唬 |
| 进阶 | 尝试范围、阻断牌、权益实现、尺度和后续街规划；不声称完整 GTO |

均衡 / 偏被动 / 偏激进与难度独立。以上是模型的行为目标，尚未做真实服务牌力评测，也不能换算真人段位。原有本地电脑评测只适用于本地策略，在线座位不显示该评测作为实力证明。

## 牌桌发言与错误恢复

发言使用独立请求，只提供公开信息和无底牌的事实摘要，不复用含私有决策的模型回复。每位 AI 每手最多尝试一次发言，不等待发言才继续下注；可在设置中关闭。底部单条紧凑消息显示最新发言，点击查看本手对话，避免多人气泡挡住牌桌。历史记录保留发言并按发生步骤显示；复盘不调用模型。

每次在线决策调用一次模型；发言会增加请求。非法操作、非法下注、格式错误、鉴权 / 限流 / 超时等均停止在原决策点；可以手动重试、配置服务，或明确让本地电脑接管该座位本手，下手恢复在线。没有自动重试或悄悄切换策略。打开菜单、设置、主界面、暂停或切后台时取消请求，过期响应不能替新牌桌行动。

## 信息边界与兼容性

请求使用字段白名单：本座位底牌、当前公共牌、公开座位筹码与下注、公开行动、合法操作和该身份记忆。不上传牌堆、未来公共牌、其他玩家未公开底牌、其它身份私有信息或历史完整底牌。筹码结算、发牌和合法操作始终由本地规则引擎决定。

远程服务接收的内容会按其政策处理，服务地址由用户选择。本应用没有托管模型服务或内置 API Key。训练室和教练保持离线，历史分支不会使用长期记忆产生未来信息泄漏。

协议依据 [Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；异步请求使用 [Godot HTTPRequest](https://docs.godotengine.org/en/stable/classes/class_httprequest.html)。未声称所有兼容厂商都通过实测。
