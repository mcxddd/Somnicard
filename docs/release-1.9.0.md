# Somnicard 1.9.0 · 河牌策略、决策教学与 AI 服务预设

本版把河牌分析从没有待跟注的局面扩展到面对下注，加入一次再加注，并让教学展示可比较的操作、参考频率和模型净值。AI 名字可手动填写或由当前模型生成候选；新增常见服务预设。

## 教学与策略

- 本手提示结合跟注价格、可争夺底池、回本份额和下注目的；不同玩家数量给出对应提醒。
- 复盘和训练比较实际选择与参考策略。混合策略中的合理选择不会仅因不是最高频操作而被标成错误。
- 收敛且尺寸在树内时，显示该操作的模型 EV，以及与表中最高模型 EV 的差。这个差值不是实际输掉的筹码，也不是具体底牌的精确损失。
- 未覆盖的尺寸不评分；未达模型内收敛目标时保留经验建议；差距落在估算误差附近时标为边缘决策。
- 策略表在牌桌教练内显示，BB / 筹码同步切换；教学保持离线。

河牌求解仍限定为剩两位活跃玩家、能完整跟注、无边池的场景。使用 8 档牌力和每方 64 个范围代表样本，支持过牌、弃牌、跟注、半池 / 满池下注、最小 / 底池再加注。每条河牌分支最多一次下注加一次再加注，已发生的进攻动作计入上限。它不是完整多人 GTO；范围误差、分桶阻断误差与有限下注尺度不包含在 CFR 收敛误差中。设计与公式见 [策略说明](strategy.md)。

## AI 名字与服务

设置 → AI 服务与陪练：选择提供商，核对模型 ID，输入该服务密钥，测试连接后保存。

| 预设 | 地址 | 模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash`，可编辑 |
| OpenAI | `https://api.openai.com/v1` | 手动填写账号可用模型 ID |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 手动填写完整模型 ID |
| 阿里云百炼 · 北京 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`，可编辑 |
| 自定义兼容服务 | 手动填写 | 手动填写 |

DeepSeek 预设默认请求 JSON 并关闭额外思考以减少等待。已适配地址可选择思考模式；尚未适配的地址禁用此控件并使用服务默认行为。具体模型仍需支持对应参数。可调整输出上限，收到截断响应时提示重试方式。百炼可换成控制台的业务空间专属地址；地域、密钥与业务空间需匹配，自定义地址不自动套用思考参数。

服务预设不自动发请求。更换服务域名会清空草稿中的旧密钥；密钥仍只保留本次运行，不写入存档或备份。

设置 → 电脑对手 → 选择座位并启用在线 AI：名字可直接输入，也可点击“AI 生成昵称”。每次点击会请求三个与模型名称、性格相关的候选，例如与 DeepSeek 的深海、探索意象关联的昵称。生成结果由模型决定，不保证固定名称。点选仅修改草稿，保存设置才应用；取消、改名、换座位或离开页面会取消未完成请求。起名请求仅带模型、性格和需避开的名字，不附牌局或陪练记忆。长期陪练身份、记忆与桌边发言延续 1.8 的规则。

预设依据 2026-10-22 查阅的官方说明：[DeepSeek 接口](https://api-docs.deepseek.com/api/create-chat-completion/)、[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[硅基流动接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)和[百炼思考参数](https://help.aliyun.com/zh/model-studio/deep-thinking)。

## 验证

16 项自动测试套件与完整牌局启动检查通过。河牌扩展新增 355 项检查：54 条终局路径逐条通过真实规则引擎结算，验证合法性、收益、面对下注的跟注公式和弃牌零收益；标准 Kuhn 验证保留。AI 套件 194 项检查通过，包含预设、无隐式请求、名字提示信息隔离、候选选择与取消、过期响应忽略、截断响应提示及跨服务密钥清空。

实际桌面渲染检查覆盖 360×640 服务预设、思考配置、候选昵称与策略表，以及 390×844 牌桌内河牌教学。真实模型服务尚未使用用户密钥联调；安卓触摸、键盘与长时间性能仍待用户体验。
