# Somnicard 1.7.0 · 主界面与导航重构

Android versionCode 18。包名、签名与存档格式沿用，覆盖安装保留本机资料。

启动先到独立主界面。首页突出开始新局；有进行中的牌桌时改为继续对局，并显示人数、手数和阶段。重启后有存档则提供恢复入口。训练室与牌局复盘使用独立入口卡片，设置与玩法帮助固定在底部。电脑与手机都保持竖屏。

## 入口层级

| 一级入口 | 二级功能 | 进一步操作 |
|---|---|---|
| 开始新局 | 新建牌桌 | 2–9 人、50/100/200 BB、配置每位对手、确认入座 |
| 继续 / 恢复对局 | 当前牌桌 | 下注、教练、座位详情；更多菜单提供设置、历史、行动记录与返回主界面 |
| 训练室 | 开始练习 / 练习记录 / 表现统计 | 主题和来源、继续练习、已保存分支、桌型和时间筛选 |
| 牌局复盘 | 历史筛选与牌局列表 | 回放、牌桌内教练、收藏、备注、关键决策与重打 |
| 设置 | 对局节奏 / 外观与显示 / 操作保护 / 教练与教学 / 电脑对手 / 数据与备份 | 分类中的具体选项；备份导入导出单独说明即时执行 |
| 玩法与帮助 | 操作说明与许可 | 当前版本入口、玩法、分析适用范围 |

新建牌桌只处理入座配置。人数、初始筹码、电脑配置顺序明确，配置摘要与开始按钮固定在底部。全局设置不再混放在选桌按钮旁；默认电脑难度与逐个对手配置集中在“电脑对手”。

训练室不再把练习、长统计、历史练习和备份串成一个长页面。备份迁到“设置 → 数据与备份”，继续使用校验、合并和不覆盖已有同名记录的格式；普通牌桌进度与设备偏好不包含在该训练备份内。

## 返回与保存

- 回主界面会暂停推进并保留当前桌；点击继续恢复原有进度。原本手动暂停的桌仍保持暂停。
- 从主界面或牌桌进入训练、复盘和帮助，返回时回到来源；训练中的原牌局与分支回放仍回到训练。
- 设置从分类进入具体页，返回分类保留草稿；保存才应用，取消修改会放弃草稿。分类入口支持触摸滚动，底部保存和取消持续可达。
- 新建桌替换已有进度仍需要确认；取消保留原桌。主界面按返回键会确认退出。

## 参考与取舍

[PokerStars 官方选桌说明](https://www.pokerstars.com/help/articles/mob-ring-game-filter/7737/)把人数、筹码深度作为选桌条件；本版据此把入座配置从全局设置中分开。[GTO Wizard 训练概览](https://help.gtowizard.com/measure-performance/)区分练习、记录和表现统计，本版采用相似的信息分组。[训练管理说明](https://help.gtowizard.com/manage-training-drills/)也提供从总览进入练习的路径。本版为原创界面实现，参考功能组织；保持离线练习定位和原有策略能力，不增加账户、真钱或完整 GTO 的暗示。
