## 发布后优先顺序

1. 收集物理手机上的渲染、键盘、音量、震动、续航和系统安装反馈，按可重复证据修复兼容性。
2. 使用用户配置的真实模型服务测延迟、成本、截断与风格；以独立评测改进对手，不凭提示词宣称达到真人水平。
3. 扩展经过审核的教学局面和针对弱项的练习安排，避免将输赢直接等同于决策好坏。
4. 逐步增加离线策略抽象覆盖，并持续显示范围、计算预算与误差；完整多人 GTO 另作研究与计算架构评估。
5. 按使用反馈决定锦标赛、网络对战、云同步等独立大功能，不将这些未实现模块放进现有导航占位。
