# Somnicard 1.1.0：美术与操作体验

Android versionCode 5，包名保持 `com.somnicard.practice`。开发调试签名用于本地安装测试。

## 视觉更新

- 统一深色界面、暖金强调色、按钮边框、输入框、下拉菜单与滑条。
- 绒面纹理、多层桌沿、筹码装饰与桌面字标；经典墨绿 / 午夜蓝两种配色。
- 原创可缩放牌面、纹样牌背和座位徽章。隐藏牌的绘制节点只持有背面标识，不持有真实牌号。
- 四色花色：黑桃黑、红桃红、方块蓝、梅花绿；可关闭的轻量发牌动效。
- 入座页增加插画与功能介绍；复盘页独立突出推荐操作、权益数字和比例条。

美术由 Godot 绘制组件实现，不需要大型位图素材；牌桌与复盘使用同一套组件。

## 操作更新

设置入口在主牌桌顶部及选桌页。游戏节奏、牌桌外观、操作保护分组；编辑时暂停牌局，应用后保存，取消丢弃修改。“恢复默认”只修改草稿，仍需应用。

全押默认要求确认，覆盖按钮全押、跟注全押、加注到全押；可在设置中关闭。重开牌桌始终确认。当前决策改变后，过期确认不能执行；重复点击确认不会重复下注。

页面共享暂停和键盘焦点规则。Esc / 安卓返回键只关闭最上层；取消设置保持原来的暂停状态；取消换桌丢弃临时桌型与深度。复盘返回按钮按来源显示“返回选桌”或“返回牌桌”。

输入框里的未提交金额会在切换页面前按原单位保存为选定金额，不会下注。所有单位、配色与牌面辅助选项同步到复盘。

## 存档与兼容

牌局 schema 未变，历史牌局与当前桌恢复保持兼容。新增设置自动使用默认值；保存偏好采用临时文件再重命名。修改外观和操作偏好不会重开牌局或改变筹码。

## 验证范围

保留规则、完整牌局、多人电脑对战、历史复盘和胜率测试；新增设置交互测试，覆盖草稿/应用/取消、旧设置迁移、原子覆盖、非法偏好回退、全押三种入口、重开桌确认、重复与过期确认、真实电脑定时器、不同人数卡牌边界与模态返回。
