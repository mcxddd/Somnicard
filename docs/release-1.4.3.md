# Somnicard 1.4.3

Android versionCode 12。重新设计牌桌上的金额视觉系统，沿用包名、签名和本地记录。

- 剩余筹码：象牙白主数字、小号独立单位，纵向排列；和手牌留出明确间距，不再把数字与 BB 挤成一串。
- 当前下注：暖金数字、独立单位、细边圆角金额牌，配带象牙色边缘刻纹的红色扑克筹码。图案中的筹码数量仅为装饰，实际金额始终以数字为准。
- 中央底池：独立“总底池 / 已分配”标题、双色筹码、突出显示的大数字；仍表示整手累计底池。
- BB 和实际筹码使用相同组件，保留 0.5 BB 等精确显示。大额以千分位分组，不使用 k / 万缩写；数字和单位根据可用空间分别排版。
- 对局与复盘顶部改为“筹码 / BB”双按钮切换，选中状态直接可见。切换单位不改变实际筹码、下注草稿或牌局状态。
- 筹码图案使用原生矢量绘制，在不同分辨率保持清楚，无新增图片下载和网络依赖。

验证：沿用完整规则及 UI 回归，重点检查 2–9 人桌金额不遮挡、0 / 0.5 BB / 18,000 筹码等数值与单位不越界、切换单位不改变牌局。实际渲染检查包含九人桌 BB、筹码模式以及复盘与摊牌。新版 Android 真机体验仍待用户确认。

9 组自动测试全部通过（金额与牌桌测试 6,940 项），UI 冒烟通过。
