# 1.11.0 实施清单

用户已于 2026-10-23 授权将全部项目纳入同一版本并开始开发。

## 交付范围与顺序

1. 多服务档案：兼容迁移 1.10 设置；服务自动发现模型；各座位独立选择服务/模型，教练独立选服务；昵称、记忆仍按身份隔离。服务变更取消过期请求。
2. 密钥安全保存：默认仅内存，可选系统保护持久化；Android Keystore AES-GCM，Windows 当前用户 DPAPI；不进入存档、历史、备份、日志和 APK。不可用时明确失败，禁止退回明文。支持取消记住与删除。
3. AI 教练：对局/复盘分别启用，保留离线建议；按需详解、快捷问题与自由问答；只发送当前决策的玩家信息白名单，不读取对手记忆或未来信息。关键数值由本地渲染，AI 解释单独标识，不承担规则和 GTO 计算。
4. 牌桌教学 UX：牌桌内面板，简短结论、具体理由、条件变化；取消、错误、过期回复处理；复盘按当前步骤隔离问答；训练先答后看。
5. 针对性训练：从已分析决策形成待复盘清单与主题练习建议；有依据才评价，混合策略/误差内差异不判错；练习与真实盈亏分开统计。
6. GTO 扩展：在手机离线预算内扩大双人河牌下注尺度（含小额下注和全押），增加可选精细分析与固定场景参考对照；明确人数、边池、范围、离散尺度与收敛边界。不是完整多人 GTO，不把模型内误差当真实误差。
7. 完整牌力评测：固定局面、独立牌序、座位轮换、2/6/9 人与 50/100/200 BB；本地三档及风格统计；在线模型复用相同评测流程，明确请求量、暂停/恢复与失败率。展示样本、区间、有效动作率、耗时、服务报告用量，未实际调用的模型保持未评测，不换算真人段位。
8. 验收与发布：迁移/信息隔离/取消/密钥测试、全套规则回归、竖屏渲染、APK 签名与权限/对齐检查、公网完整下载与续传。真机和使用用户密钥的真实模型评测单独记录，不以模拟请求代替。

## 完成记录

八项实现与本地 / 静态验收已完成，1.11.0 已发布并通过公网完整下载和 Range 续传验证。功能、测量结果和限制见 [版本说明](release-1.11.0.md)，下载核验见 [发布记录](server-download.md)。

本地评测 21,312 手；六个固定河牌抽象以独立 LP 核对；17 个测试套件与启动检查通过。未取得用户模型密钥，因此真实在线模型实力尚未评测；安卓 Keystore 仅完成编译 / 静态验证，真机操作仍由用户后续确认。这些项目没有标为实测通过。
