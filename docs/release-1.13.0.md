# Somnicard 1.13.0

模型选择改为适合触摸的搜索列表；AI 对手的请求记录放进座位详情，桌边发言改为座位气泡。

## 选择模型

设置 → AI 服务与陪练 → 获取模型 → 点当前模型。独立面板提供固定搜索框、可上下滑动的模型列表和选中标记。拖动不会选中模型；点选才应用到草稿，保存设置后生效。安卓返回键先关闭模型选择，再回到设置分类。临时失焦只取消网络请求，保留模型选择页，避免返回时跳过一层。Android 16 的同一次返回按键可能产生两个返回通知，现对 350 毫秒内的重复通知合并处理；连续的两次正常按键仍按层级返回。

长目录每批显示 60 个结果，可搜索名称或模型 ID，也能继续显示更多。列表独占拖动，背后的设置页不会同时滚动。手动填写模型仍保留。

## 回复长度与自动恢复

原先每次生成固定限制为 4096 tokens；收到 `finish_reason=length` 或 Messages 的 `stop_reason=max_tokens` 就暂停，和玩过几轮无关。推理模型的生成额度可能包含不可见的推理 tokens，所以可见答案很短，也可能耗尽额度。依据：[OpenAI 输出 token 计数](https://developers.openai.com/api/docs/guides/token-counting)、[Chat Completions 参数与结束原因](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。不同兼容服务的具体原因以实际响应为准。

现在对明确的生成截断最多扩大到 16384 tokens 重试一次。成功后本次运行对同一地址、模型、接口格式和密钥复用成功的额度，避免每一步重复先触发截断。与参数兼容重试共享最多 4 次 HTTP 请求上限；评测调用也遵守传入的剩余预算。不使用不完整 JSON 决策，不在超时、429、鉴权错误后循环重试。

自动重试可能产生额外服务商用量；统计包含有报告的截断生成。记录分别展示输入、输出和服务报告的推理 token 数；未报告用量时显示未知。仍失败时保留手动重试、本手本地接管、配置服务入口。

## 对手详情与请求记录

点对手座位框，在线 AI 的详情新增“桌边发言”和“API 请求”。请求按该座位、手数、下注轮次、决策 / 发言目的和尝试次数分开，显示发送的 JSON、模型可见回复、HTTP 状态、结束原因、生成上限、耗时、用量，以及合法决策是否执行、发言是否被过滤或过期。

当前手的发送内容和回复要等该手结束后解锁，避免通过调试信息看到对手手牌。结束后重新进入详情查看；之前已完成手的记录在本桌后续牌局中也可查看。进入单条记录收起重复的座位信息，支持复制本条脱敏记录。

记录仅存本次运行的牌桌内存，最多 160 次请求和 2 MB，最旧的先清理；较长的单条内容会注明截短。新建牌桌、退出游戏会清除，也可主动清空。记录不进入存档、备份、长期陪练或公开服务器。请求头、密钥和模型内部推理内容不记录；已知密钥与 Bearer / 常见密钥格式额外脱敏。

## 座位气泡

AI 发言从说话者的座位旁显示浅色气泡，尾部指向该座位，点击可进入对手详情。同时只显示最新一条，6.5 秒后收起；每位 AI 每手的发言请求限制沿用上一版，不增加自动刷屏。默认避开座位、手牌、下注筹码、公共牌、底池和结算区域。极紧凑训练视图无空间时只保留座位详情里的记录。

普通发言不再占下方操作区；连接失败和本地接管状态仍提供恢复入口。复盘中的发言也使用座位气泡，按原行动步骤出现；不会提前展示未来发言。发言继续使用仅含公开信息的独立请求，与私有决策隔离。

## 验证范围

21 个自动测试套件及启动检查通过，共 171,384 项断言；新增版本专项 864 项、AI 接口专项 330 项。连续压力测试完成 2,795 手、12,537 次操作和 1,530 次中途恢复。检查实际渲染的模型选择、六 / 九人气泡、请求列表、当前手锁定和结束后详情。

Android 14 / 16 模拟器验收与发布包检查见 [本版安卓测试记录](test-android-1.13.0.md)。没有使用真实外部模型密钥，模拟的截断 / 用量不能证明某个服务的真实费用、语言质量或牌力。
