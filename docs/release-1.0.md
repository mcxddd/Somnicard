# Somnicard 1.0.0 离线练习版

完成日期：2026-10-22。Android versionCode 4，包名 `com.somnicard.practice`。

## 包含的功能

- 2–9 人选桌，双人 / 6 人 / 9 人快捷选择，50 / 100 / 200 BB 初始筹码。
- 完整四轮下注、摊牌、主池 / 边池、未跟注金额退还、短码全押和连续下一手。
- 独立的本地电脑、多人布局、三档速度、暂停、弃牌后快进。
- BB / 筹码切换，快捷 BB 档位、底池比例、滑条与明确提交。
- 本地历史列表、逐步回放、按街道跳转、跳转自己的决策、自动播放并在自己的决策点暂停。
- 实时及复盘建议：只用当时已知信息，随机对手范围下的蒙特卡洛权益、平局、边池赔率、启发式推荐和原因。
- 当前牌桌自动保存与启动后恢复；后台暂停；损坏存档提示；玩法帮助与离线组件许可。

## 运行与交付

桌面：`powershell -ExecutionPolicy Bypass -File tools/run.ps1`。

安卓：`builds/android/somnicard-debug.apk`。用 `tools/export-android.ps1` 可重新生成；本包使用开发调试签名，适合安装测试，不是商店发行签名。应用无需网络权限，不含账户、支付或远程服务。

同包名、同签名更新安装可保留应用数据。卸载或清除应用数据可能移除历史与当前桌存档。

## 已知限制

- 尚未连接安卓真机；中文系统字体、触摸/软键盘、返回键、后台切换与性能仍需设备实测。
- 电脑是基础规则策略；建议是随机范围基线与教学启发式，不是 GTO 或最优收益承诺。
- 多人连续牌局采用移动庄家的简化练习规则，未实现完整锦标赛死庄、盲注升级与比赛管理。
- 存档仅在本机，无云同步和导入分享；模拟不建模对手范围学习、弃牌率与未来下注。
- 界面主要面向横屏；未提供竖屏布局、音效或发牌动画。
