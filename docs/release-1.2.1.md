# Somnicard 1.2.1：手机与电脑统一竖屏

按用户要求，所有平台只使用竖屏界面，后续也按这一方向开发。Android 保持 portrait，电脑普通启动和 Godot F5 默认打开 450×850 窗口，无需 `-Portrait` 参数；旧参数保留为兼容别名。

游戏逻辑宽度固定为 540，纵向随屏幕比例扩展。拉宽或最大化电脑窗口时，游戏居中保留竖屏区域，两侧留空；加注、设置、复盘和菜单始终位于这个区域内。调整窗口保留当前牌局、已填写的金额、打开的加注面板、设置草稿与复盘步骤。

移除方向切换入口和横屏专用的侧栏开关。行动记录统一从“更多 → 本手行动记录”查看。旧版侧栏偏好仅为兼容保留，不再控制可见布局；已有牌局与存档不变。

验证包含默认启动的实际渲染、1280×800 宽窗口居中的竖屏画面，以及 360×640、390×844、412×915 的 2–9 人牌桌检查。竖屏交互检查共 1423 项通过，既有规则、UI、多人对战、复盘、设置及完整启动回归通过。
