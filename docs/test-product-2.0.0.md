# 2.0.0 产品候选版验收

日期：2026-10-23。**不是正式发布证书**：安装签名身份尚待决定；未上传 2.0 APK，未完成确切 Release 文件的安装、迁移与公网校验。

## 桌面与规则

`tools/check.ps1` 完成 22 套规则 / UI / 数据 / AI / 策略测试，共 171,515 项检查，并通过完整牌局启动检查，最终记录 `.local/product-final2-regression.log` 无失败。

持续规则压力测试：2,795 手牌、12,537 次动作、1,530 次中途恢复，128,136 项检查。覆盖 2–9 人、筹码守恒、下注合法性、结算与复盘一致性。

本版产品测试 146 项，覆盖 24 个问题的错误 / 正确作答、知识点不重复计数、课程备份合并、非法导入数据、两种竖屏尺寸的导航焦点、课程转主题训练、帮助与隐私入口、声音与性能设置、反馈去重、输牌不播放获胜提示、后台停音和诊断摘要不含敏感配置。

最终导航测试也确认牌桌与首页使用同一个帮助中心，分层返回保留当前牌桌。全量回归后只更正了一道题的措辞（将“牌堆里”明确为“未知牌中”），答案和控制流程未改变。

最后加入品牌启动与统一帮助入口后，重新运行全量桌面检查，并构建、安装最终源码的独立候选 APK，在 API 36 验证冷启动进入主页。首次更新后出现一次着色器缓存失效重编译提示，随后正常进入主页；没有脚本或 Java 崩溃。正式包仍须单独验收。

## 视觉与官网

检查实际渲染：360×640 的主页、课程问题、帮助、6 / 9 人桌，以及 390×844 的答题解释。真实安卓截图覆盖牌桌、课程和模型配置等流程。提示音为可重复生成的 5 个原创 PCM 资源；物理设备听感和震动尚未测试。
