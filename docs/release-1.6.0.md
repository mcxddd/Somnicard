# Somnicard 1.6.0

Android versionCode 15，沿用包名和调试签名，可覆盖安装。手机与桌面继续统一竖屏。

## 对手策略与独立配置

- 三档采用不同策略：入门偏宽跟注且位置意识弱；标准结合位置、跟注价格、听牌与多人底池；进阶比较有限的一轮下注响应与多个尺寸，并约束价值下注、半诈唬和纯诈唬的频率。完全离线，均不读取其他人的真实底牌。
- 每位电脑可分别选择难度、均衡 / 偏被动 / 偏激进。开桌页“对手 / 设置”，或对局中点电脑座位 → 配置这位对手。
- 跟随默认的座位随全局难度改变，独立设置的座位保持不变；减少人数仍保留未使用座位的配置。默认全部均衡，替代过去自动循环的三种风格。
- 设置是草稿，应用后从下一次电脑决策生效；取消、返回丢弃。窄屏采用座位网格与单人编辑器，底部取消 / 应用始终固定；支持触摸拖动。
- 自动恢复保留逐座位配置及默认难度继承关系。历史保存配置时间边界，复盘与重打使用当时配置；训练恢复保留自己的配置快照。没有这类元数据的旧历史仍可使用。

## 客观评测结果与限制

冻结测试 18,432 手：1,024 个独立牌序块、100 BB、无抽水；双人全配对及冻结的 1.5 标准基线，6 / 9 人为三档均匀混合桌，所有强度测试为均衡风格。同牌轮换座位，以独立牌序块计算 95% 区间。

- 标准对入门：+84.1 BB/100，95% 区间 [+37.5, +130.7]。
- 进阶对入门：+83.7 BB/100，95% 区间 [+35.1, +132.4]。
- 进阶对标准：+7.9 BB/100，95% 区间 [-20.5, +36.2]。

入门较弱有实测支持。标准与进阶尚未稳定分出高下，进阶标为“实验”；新标准 / 进阶对旧版标准也没有显著优势证据。设置页可展开实测范围和结果。不能将特定电脑阵容的收益率换算成真人段位或真人桌盈利率，不能称为完整 GTO。另有 1,152 手九人混合风格测试。完整方法、全部结果、配对差值、行为统计及原始数据见 [对手设计与实测](opponents.md)。
