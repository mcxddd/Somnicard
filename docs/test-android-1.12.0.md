# 1.12.0 Android 模拟器验收

测试日期：2026-10-23。使用官方 Android SDK Emulator 37.2.12，在本机安装两个独立 AVD。没有连接实体手机。

## 环境与隔离

| 设备 | 系统 | 镜像 | 实际检查分辨率 |
| --- | --- | --- | --- |
| Somnicard_API36 | Android 16 / API 36 | default x86_64，修订 2 | 720×1600，320 dpi |
| Somnicard_API34 | Android 14 / API 34 | default x86_64，修订 4 | 720×1280，320 dpi |

使用已有 SDK / JDK，通过官方工具安装 Emulator 与系统镜像。CPU 使用现有 WHPX 加速，图形使用电脑显卡的 host 后端；没有修改 Windows 虚拟化功能、BIOS、安全服务，也没有重启电脑。

AVD 数据保存在 `.local/android-avd/api36` 和 `api34`，系统镜像在现有 Android SDK 中。模拟器启动配置注册在用户的 `.android/avd/`。均为本次新建的测试设备，未读取真实手机或真实用户密钥。

软件图形后端 SwiftShader 启动游戏时出现 GLES 着色器 uniform 上限错误与黑屏，切换 host 后端后正常。模拟器对真机显卡、性能、发热和耗电的代表性有限，不能从本机运行速度推算手机性能。

## 发布包的实际安装与触摸

- 在 API 36 安装已发布的 1.11.1，实际开六人桌；强制停止后记录 `session.json` 与 `preferences.cfg`，覆盖安装新版后逐字节比对不变。实际点击恢复按钮，原手牌 / 筹码 / 进度恢复并保持暂停，新对手名字生效。
- API 34 实际安装新版，使用 Android 触摸事件打开设置、逐座位改名，保存后读取测试设备的配置核对名字。没有通过修改配置文件伪造输入结果。
- 实际安卓返回键暴露了引擎自动退出的问题；修复后从设置详情返回分类时 PID 不变，保留未保存的草稿。安卓返回逻辑纳入自动回归。
- API 36 检查切到主屏幕后返回，牌桌保持暂停；当前牌桌和进度仍可继续。
- API 34 检查真实软键盘与设置面板避让，通过点击软键盘字母 `a` 并保存，核对名字从“小夏Test”变为“小夏Testa”。输入框及保存按钮在键盘上方，收起键盘后恢复面板高度。

模拟器额外暴露 `AT Translated Set 2 keyboard`，Godot 因检测到硬件键盘而抑制软键盘。已核对本地引擎 Java 实现，在 API 34 虚拟设备内部临时断开该模拟键盘，才执行手机软键盘验收；没有修改电脑键盘或游戏的输入系统。此操作仅在该次 AVD 启动期间有效，重启设备后可能需重做。

部分 headless 截图中的键盘区域呈黑色，但输入服务报告键盘已显示，屏幕位置点击产生的真实 IME 输入及保存值均通过；不据这些截图评价键盘皮肤。设置页输入框和按钮位置已经实测与截图检查。

## 同源 Android 自动验收

为运行可重复断言，另构建 `com.somnicard.audit` 测试应用。它与发布包使用逐文件 SHA256 核对过的相同游戏脚本、资产和原生 Keystore 插件，增加专用测试入口，使用独立数据目录。该入口、模拟密钥、测试脚本与记录不进入发布 APK，也不上传下载服务器。

每个系统 **441 项断言，0 项失败**：

- 2～9 人逐桌走完翻前、翻牌、转牌、河牌与摊牌，逐动作检查合法性和筹码守恒；还原完成的历史。
- 实际渲染双人、六人、九人牌桌、对手手牌、胜负反馈、复盘、训练和逐座位设置。每个系统保留 11 张游戏视口截图。
- 所有设置分类的保存按钮保持在可达区域，本地改名字段可见。
- 六人混模型同桌，交替路由两个模型与各自的模拟密钥，通过 Android 网络栈连接主机模拟服务，完成牌局并显示公开发言。没有请求外部模型。
- 原生 Keystore 插件实际加载；加密保存、立即读取、端点绑定、强制停止再启动读取、外部修改密文后 GCM 拒绝、关闭记住后删除均通过。由 ADB 额外检查不备份目录中的文件、无模拟密钥明文和删除结果。

Keystore 运行在模拟设备的应用 UID 内，验证系统 API 的行为；没有证明硬件密钥或 StrongBox 能力。测试结束没有遗留模拟密钥。

证据：`.local/android-audit/api34/report.json`、`api36/report.json`、各自的截图和 `logcat.txt`。没有脚本异常或 Java 崩溃；启动日志有重新编译着色器缓存的警告，不据此认定崩溃。

复现入口：先运行 `tools/prepare-android-audit.py`，在生成的隔离项目中准备模板并导出测试 APK；运行 `tools/android-mock.py`，通过 `tools/run-android-audit.py emulator-5554` / `emulator-5556` 执行。驱动只接受这两个显式测试序列号，会清空测试应用 `com.somnicard.audit`，保留正式游戏 `com.somnicard.practice` 的数据。

## 桌面回归与限制

20 个自动测试套件与启动检查通过；本轮包括固定种子 2,795 手、12,537 次动作与 1,530 次中途 JSON 恢复。实际安卓发现问题后，追加新版专项 43 项、导航 224 项、跨功能 1,606 项回归，均通过；各套件取最后一次结果合计 170,494 项断言。

测试未覆盖真实外部模型的语言质量、费用与牌力，也没有真人触摸手感、物理设备硬件安全、发热 / 耗电或长时间移动网络验证。对手发言的自然程度仍取决于所选模型，过滤测试不能代替真实模型试听。

安装包与公开下载回执见 [服务器下载](server-download.md)。官方工具依据：[模拟器硬件加速](https://developer.android.com/studio/run/emulator-acceleration)、[SDK 管理](https://developer.android.com/tools/sdkmanager)、[模拟器启动参数](https://developer.android.com/studio/run/emulator-commandline)。
