# Somnicard 1.4.1

Android versionCode 10，保留包名、签名、历史记录与设置存储路径，可覆盖安装。

- 每个座位内侧显示图形筹码和本轮投入金额，跟随 BB / 金额切换。中央底池继续显示整手累计投入，座位标记不是额外的底池；进入下一轮清空座位投入标记，结算后隐藏。
- 名字只显示玩家身份。移除重复的位置后缀和非位置座位数字徽章，仅保留 D、SB、BB 图标；双人庄家同时显示 D 与 SB。盲注与行动规则未改变。
- 对手在未弃牌时始终显示两张牌背，实际摊牌后翻开；弃牌对手不公开手牌。剩余筹码在牌背与摊牌状态下都保持可见，行动状态不再重复下注数值。
- 结算后点击悬浮教练直接进入刚结束的牌局，并定位自己的决策；按复盘教学开关决定是否计算建议。不会跳到另一手历史，也不会把摊牌信息用于之前的决策。
- 复盘移除回放 / 分析两个页面的切换。点击悬浮头像展开牌桌内分析浮层，自己的手牌、建议与理由优先展示；详细概率、范围和结算可向下滚动查看。公共牌、时间轴及回放控制保持可见。
- 分析随回放决策更新。收起或第一次返回取消计算、回到完整牌桌；再返回退出复盘。教练页中的教学开关独立保存。

规则核对：[PokerStars 多人德州规则](https://www.pokerstars.com/poker/games/texas-holdem/)、[PokerStars 双人顺序](https://www.pokerstars.com/poker/learn/news/strategy-to-play-heads-up-poker/)。多人庄家左侧顺时针依次小盲、大盲，翻前大盲左侧先行动；双人庄家兼小盲，翻前先行动，翻后大盲先行动。仍是连续练习桌，未扩展完整锦标赛死庄规则。

验证：9 组自动测试均通过，包括原规则、历史、策略与界面回归。新增 2–9 人桌下注标记防遮挡、BB 切换、牌背与摊牌、双人 / 多人盲注顺序、跳过空座、庄家轮转、结算后教练进入同一手牌、复盘同屏与返回流程。实际渲染检查包含 360×640 的双人 / 九人牌桌、摊牌与复盘浮层。新版 Android 触摸体验仍待用户确认。
