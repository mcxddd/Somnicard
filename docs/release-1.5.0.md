# Somnicard 1.5.0

Android versionCode 14；沿用包名、调试签名、旧牌局记录和当前桌存档。手机与电脑统一竖屏。

## 训练流程

- 新增训练室：四个主题（翻前入池、面对下注、加注尺度、河牌判断），从全部、收藏、待复习、自己的历史或固定练习中选择。
- 固定练习包含 8 手可确定性重放的牌局、32 个自己的决策点，覆盖双人、六人和九人。它们提供可计算局面，不是专家标注的 GTO 标准答案。
- 每组最多 5 题，优先安排较少练习的局面。先提交合法操作及金额，再显示建议、当前理由、候选打法和适用范围；支持标记“还没理解”。不按是否选中最高频动作打对错分数。
- 可以用自己提交的操作继续打完，电脑按各自信息行动。保留原牌模式保留原牌堆；重新采样模式保留自己手牌、已发公共牌、全部公开行动，按现有范围模型联合采样其他底牌并重洗其余未知牌。范围仍为经验模型，采样不构成精确反事实或完整 GTO。
- 重打输赢独立保存，不计入真实对局统计；回放工具可以切换原牌局与分支。历史局面提示可能已经知道结果，单次结果不代表长期策略收益。
- 自动保存本组进度、已提交答案及进行中的分支；恢复后先暂停。切到后台暂停重打。普通对局存档与历史均不被练习替换。

## 复盘与教练

- 复盘顶部“工具”包含收藏、待复习、五类标签、最多 2000 字备注、练习此处、关键决策跳转。工具收起后保持牌桌面积。
- 关键决策列出自己的操作位置、大额投入、全押与加注；已完成分析的点补充边缘判断或不同选择标记。未分析的点不会提前宣称是错误。
- 对局设置新增“先行动，再看教练”：不提前给建议，行动后暂停，解释动作之前的信息，返回后继续。
- 教学区分受限双人河牌参考、经验建议和边缘判断；混合策略允许多种参考动作。完整多人 GTO 未实现。

## 训练档案与备份

- 训练报告显示次数、不同局面数、各主题的待理解与不同选择数量，并建议下次练习主题；最近十次练习可再次作答。
- 真实对局统计按人数与时间筛选，显示样本量、净 BB、VPIP、PFR。训练次数是累计口径；VPIP 为翻前主动跟注或加注，PFR 为翻前加注，排除单纯交盲注。短期盈亏不是实力评分。
- 收藏、备注、练习记录与分支保存在独立训练档案。通过系统文件选择器导出 / 导入 JSON 备份，包含完整牌局及底牌、标记、答案和分支；没有上传服务。
- 导入完整校验所有牌局后再合并，重复导入不重复追加；已有同名标记优先保留，本机未完成练习优先保留。导入上限 5000 手、64 MB。备份恢复损坏档案时先保留损坏副本。
- Android 文件选择器依赖系统支持；未连接真机验证其具体系统界面。正常游戏与训练无需额外网络权限。

## 验证与边界

新增训练测试覆盖公开信息隔离、52 张无重复采样、完整分支重放、源记录不变、备份幂等与损坏拒绝、跨界面导航、进度恢复、原局 / 分支切换、行动后教练暂停。固定河牌案例验证公共牌皇家同花顺平分和独有皇家同花顺权益；边缘决策与混合频率反馈单独检查。实际渲染检查包含 360×640 九人训练和 390×844 训练室。

没有接入大模型、完整多人均衡求解或联网对战。安卓真实触摸、系统文件选择器和长时间性能仍待设备体验确认。

11 组回归测试全部通过；训练测试覆盖 32 个局面、201 项检查。UI 冒烟通过。
