# Somnicard 2.1.3

一款离线的竖屏德州扑克练习游戏，使用虚拟筹码。

## 主要变化

- 牌桌更清楚：对手有了头像和人物介绍；行动显示为彩色标签；摊牌时直接标出牌型，获胜的五张牌有金边；轮到你时先告诉你上一个人做了什么。
- 下注面板重做：大号金额配 − / +，按底池比例快速选择，翻牌后显示约占底池多少。
- 按钮统一：层级、尺寸和质感一致，按下有反馈；顶栏改为图标；弃牌、跟注、加注、全押颜色更好区分。
- 新建牌桌、对手配置、设置和复盘历史换成新样式：并排选择代替下拉框，历史列表显示底牌和输赢，筛选改为标签。
- 主界面新增“最近表现”：近 30 手净胜、入池率、训练掌握率和连续练习天数。
- 新增显示大小设置（小 / 标准 / 大）。

## 安装

可以直接覆盖安装 2.1.x（包名 `com.somnicard.game`），记录会保留，存档与备份格式没有变化。

请将下载文件的 SHA-256 与附带的 `.sha256` 文件核对。
