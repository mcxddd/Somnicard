# Somnicard 2.2.0

一款离线的竖屏德州扑克练习游戏，使用虚拟筹码。

## 主要变化

- 每桌最多 6 人。旧版的 7–9 人进行中牌桌无法恢复，7–9 人的历史记录不再读取；其余记录、训练进度和备份不受影响。
- 新增预先求解的翻牌前参考：15 BB 以内的全押 / 弃牌均衡表，以及 100 BB 的近似开局表（开池、3-bet、4-bet、全押）。教练和进阶电脑在表覆盖的局面里直接使用。
- 转牌剩两人时，教练会计算转牌和河牌的简化均衡；复盘里可以用“精细转牌分析”追加计算时间。
- 教练新增“对手可能拿着”：按强牌、中等牌、听牌、空气给出比例和最常见的起手牌，并参考你为每位电脑设定的难度。
- 进阶电脑更强：同牌对比中对上一版进阶 +16.1 BB/100，对标准 +41.8 BB/100（双人桌 100 BB，各 4 万手）。
- 新建牌桌新增 15 BB 初始筹码，用来练短筹码。
- 复盘回放有筹码动画；训练结果页改为每题一张卡片。
- 修复部分 Android 手机上中文标点紧跟英文或数字时显示成方框的问题（例如“加注到 2.5 BB，轮到你行动”）。

所有求解都是简化模型，适用范围和误差写在“帮助”与项目文档里，不代表完整的德州扑克 GTO。
